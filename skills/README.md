# Ops-core Gold skills (deploy template)

Thin, sanitized cards for an Alfred-like lab. Adapt CIDRs and paths to your host.

| Skill | Use when |
|-------|----------|
| [coach-this-prompt](coach-this-prompt/) | `Coach this Prompt:` — reorder thoughts → agent message |
| [docker-ufw](docker-ufw/) | Docker publishes vs UFW / DOCKER-USER |
| [safe-script-production](safe-script-production/) | Dry-run / CONFIRM mutators; careful edits |
| [vram-runtime](vram-runtime/) | MAX_LOADED=1, flock, FIM on-demand |
| [bronze-context](bronze-context/) | Rolling summarize before ctx overflow |
| [skill-gold-authoring](skill-gold-authoring/) | Writing new Gold cards |

**Not included:** estate IoT, digests/msmtp, Sentinel, soft-parked printer/voice,
disk-usage with private mount paths. See [docs/PRIVATE_VS_TEMPLATE.md](../docs/PRIVATE_VS_TEMPLATE.md).
