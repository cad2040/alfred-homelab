# Sentinel (public example)

Full nightly observer package: host/Docker/network telemetry, SQLite retention,
security + stability LLM passes (including optional controller NHS), morning
digest, optional mail/backup/memory hooks. Thin launcher + `lib/` modules.

**Start here:** [SETUP.md](SETUP.md) · copy [.env.example](.env.example) to a
private env file (never commit secrets or personal directory trees).

```bash
./run-sentinel.sh
```

Guide: [docs/guides/nightly-sentinel.md](../../docs/guides/nightly-sentinel.md).
